Contexto de nuestro Proyecto:

Nuestro Proyecto web multi-página desarrollado con tecnologías nativas (HTML5, CSS3 y JavaScript) para visualizar un catálogo de videojuegos con mejores ofertas. Creado como parte de un trabajo académico.

Estructura de nuestro Proyecto
index.html: Página de bienvenida y resumen de descuentos destacados.
catalogo.html: Listado principal de videojuegos en oferta, con precios y botones de interacción.
contacto.html: Vista para el inicio de sesión de usuarios.
registro.html: Formulario de registro para nuevos miembros.
styles.css: Hoja de estilos unificada con diseño plano y minimalista.
function.js: Script simple en JavaScript nativo para manejar las alertas de compra y la simulación de envío de formularios.
